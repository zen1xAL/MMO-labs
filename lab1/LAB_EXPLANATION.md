### Задание 1.1. Сумма нечётных цифр натурального числа

#### 1. Условие
Найти сумму нечётных цифр введённого натурального числа.

#### 2. Объяснение логики
- **Что такое натуральное число**: целое положительное число строго больше нуля ($1, 2, 3, \dots$). Если передано число $\le 0$, программа сразу сообщает об ошибке с помощью `raise ValueError`.
- **Как разобрать число на цифры**: в Python целое число (`int`) нельзя просто перебрать по разрядам. Поэтому число сначала превращается в строку текста: `str(number)`. Например, число `12345` превращается в строку `'12345'`.
- **Выделение нечётных цифр**: мы проходим по каждому символу строки, переводим символ обратно в число `int(ch)` и проверяем его чётность операцией деления с остатком на 2: `d % 2 != 0`. Нечётные цифры (1, 3, 5, 7, 9) дают остаток 1 и попадают в список.
- **Подсчёт суммы**: встроенная функция `sum()` складывает все отобранные нечётные цифры.

#### 3. Код решения
```python
from typing import List, Tuple

def get_sum_of_odd_digits(number: int) -> Tuple[int, List[int]]:
    if number <= 0:
        raise ValueError("Число должно быть натуральным (> 0).")

    # Преобразуем число в список цифр
    digits = [int(ch) for ch in str(number)]
    # Оставляем только нечётные цифры
    odd_digits = [d for d in digits if d % 2 != 0]
    # Находим их сумму
    total_sum = sum(odd_digits)
    
    return total_sum, odd_digits
```

#### 4. Пример работы
- **Вход**: число `371524`
- **Процесс**: цифры `[3, 7, 1, 5, 2, 4]`. Нечётные: `[3, 7, 1, 5]`. Сумма: $3 + 7 + 1 + 5 = 16$.
- **Выход**:
  ```text
  Число: 371524
  Нечётные цифры: [3, 7, 1, 5]
  Сумма нечётных цифр: 16
  ```

### Задание 1.2. Пары регистров и подсчёт согласных букв

#### 1. Условие
Посчитать, сколько пар (стоят рядом) верхнего и нижнего регистра находится в введённом с клавиатуры слове (Пример `HjkLM` — 1 пара нижнего, 1 пара верхнего), а также сколько согласных букв в слове.

#### 2. Объяснение логики
- **Что такое пары регистров**: пара — это два соседних символа.
  - Пара нижнего регистра: оба символа строчные (маленькие), например `'jk'`.
  - Пара верхнего регистра: оба символа заглавные (большие), например `'LM'`.
- **Как пройтись по парам**: мы используем цикл с шагом по индексам от `0` до `len(word) - 2` (то есть до предпоследнего символа). На каждом шаге сравниваем символ `word[i]` и стоящий сразу за ним символ `word[i + 1]`.
- **Как считать согласные**: мы заранее создаем множество (`set`) всех согласных букв русского и латинского алфавита. При проверке переводим текущую букву в нижний регистр `ch.lower()` и проверяем: `ch.lower() in CONSONANTS`. Поиск в `set` работает мгновенно.

#### 3. Код решения
```python
from typing import Dict

CONSONANTS = set("bcdfghjklmnpqrstvwxyzбвгджзйклмнпрстфхцчшщ")

def analyze_word(word: str) -> Dict[str, int]:
    lower_pairs = 0
    upper_pairs = 0

    # Проходим по соседним парам символов
    for i in range(len(word) - 1):
        c1, c2 = word[i], word[i + 1]
        if c1.islower() and c2.islower():
            lower_pairs += 1
        elif c1.isupper() and c2.isupper():
            upper_pairs += 1

    # Подсчитываем согласные буквы
    consonants_count = sum(1 for ch in word if ch.lower() in CONSONANTS)

    return {
        "lower_pairs": lower_pairs,
        "upper_pairs": upper_pairs,
        "consonants_count": consonants_count,
    }
```

#### 4. Пример работы
- **Вход**: слово `"HjkLM"`
- **Процесс**:
  - Пары: `('H','j')` — разный регистр; `('j','k')` — обе строчные (1 пара нижнего); `('k','L')` — разный регистр; `('L','M')` — обе заглавные (1 пара верхнего).
  - Согласные буквы: `H`, `j`, `k`, `L`, `M` (все 5 букв являются согласными).
- **Выход**:
  ```text
  Слово: 'HjkLM'
  Пары нижнего регистра: 1
  Пары верхнего регистра: 1
  Количество согласных букв: 5
  ```

### Задание 1.3. Обработка гетерогенного списка

#### 1. Условие
Дан список `list = [1612, 49, 'hello', 6, 19, 'world']`.  
- Все числа проверить на чётность: если чётное — посчитать сумму его цифр; если нечётное — заменить на `1` в списке.
- Все слова: посчитать количество гласных и согласных.  
Вывести всё на экран.

#### 2. Объяснение логики
- **Гетерогенный список** — это список, в котором одновременно лежат элементы разных типов: целые числа (`int`) и строки (`str`).
- **Разделение логики через `isinstance`**:
  - Если элемент — число (`isinstance(item, int)`):
    - Проверяем чётность: `item % 2 == 0`.
    - Для чётного (`1612`, `6`): берем его цифры и суммируем: $1+6+1+2=10$.
    - Для нечётного (`49`, `19`): заменяем элемент на число `1` на той же позиции в списке.
  - Если элемент — строка (`isinstance(item, str)`):
    - Считаем гласные буквы по множеству `{'a','e','i','o','u','y'}`.
    - Считаем согласные буквы по множеству согласных.

#### 3. Код решения
```python
VOWELS = set("aeiouyаеёиоуыэюя")
CONSONANTS = set("bcdfghjklmnpqrstvwxyzбвгджзйклмнпрстфхцчшщ")

def process_mixed_list(raw_list: list):
    modified_list = list(raw_list)  # создаем копию для изменения
    words_info = []
    even_numbers_info = []

    for index, item in enumerate(raw_list):
        if isinstance(item, int):
            if item % 2 == 0:
                digits_sum = sum(int(ch) for ch in str(abs(item)))
                even_numbers_info.append((item, digits_sum))
            else:
                # Нечётное число заменяется на 1
                modified_list[index] = 1
        elif isinstance(item, str):
            v_cnt = sum(1 for ch in item.lower() if ch in VOWELS)
            c_cnt = sum(1 for ch in item.lower() if ch in CONSONANTS)
            words_info.append((item, v_cnt, c_cnt))

    return modified_list, even_numbers_info, words_info
```

#### 4. Пример работы
- **Вход**: `[1612, 49, 'hello', 6, 19, 'world']`
- **Выход**:
  ```text
  Исходный список: [1612, 49, 'hello', 6, 19, 'world']
  
  Чётные числа:
    1612: сумма цифр = 10
    6: сумма цифр = 6
  
  Слова:
    'hello': гласных = 2, согласных = 3
    'world': гласных = 1, согласных = 4
  
  Итоговый список (нечётные заменены на 1):
  [1612, 1, 'hello', 6, 1, 'world']
  ```

### Задание 1.4. Сортировка словаря по значению

#### 1. Условие
Отсортируйте словарь по значению в порядке возрастания и убывания.

#### 2. Объяснение логики
- **Как устроен словарь**: он состоит из пар «ключ : значение». По умолчанию метод `sorted(dict)` сортирует только ключи.
- **Сортировка по значению**:
  - Метод `data.items()` возвращает список кортежей вида `(ключ, значение)`.
  - С помощью параметра `key=lambda item: item[1]` мы указываем функции сортировки брать именно второй элемент кортежа (то есть значение).
  - Для сортировки по убыванию добавляем флаг `reverse=True`.
  - Полученный отсортированный список пар превращаем обратно в словарь `dict(...)`.

#### 3. Код решения
```python
def sort_dict_by_value(data: dict):
    # Сортировка по возрастанию значений
    asc = dict(sorted(data.items(), key=lambda item: item[1]))
    # Сортировка по убыванию значений
    desc = dict(sorted(data.items(), key=lambda item: item[1], reverse=True))
    return asc, desc
```

#### 4. Пример работы
- **Вход**: `{'яблоко': 45, 'банан': 20, 'груша': 85, 'киви': 15}`
- **Выход**:
  ```text
  По возрастанию цены:
  {'киви': 15, 'банан': 20, 'яблоко': 45, 'груша': 85}

  По убыванию цены:
  {'груша': 85, 'яблоко': 45, 'банан': 20, 'киви': 15}
  ```

### Задание 1.6. Сортировка кортежа

#### 1. Условие
Дан кортеж целых чисел. Отсортировать его по убыванию. Вывести первый и последний элемент кортежа.

#### 2. Объяснение логики
- **Особенность кортежа (`tuple`)**: кортеж является неизменяемым типом данных (у него нет метода `.sort()`).
- Чтобы его отсортировать, мы передаем кортеж в функцию `sorted(t, reverse=True)`. Она возвращает новый отсортированный список, который мы обратно упаковываем в кортеж: `tuple(...)`.
- **Первый и последний элементы**:
  - `sorted_t[0]` — первый (он же наибольший при сортировке по убыванию);
  - `sorted_t[-1]` — последний по отрицательному индексу (он же наименьший).

#### 3. Код решения
```python
def sort_tuple_descending(numbers: tuple):
    sorted_t = tuple(sorted(numbers, reverse=True))
    first_elem = sorted_t[0]
    last_elem = sorted_t[-1]
    return sorted_t, first_elem, last_elem
```

#### 4. Пример работы
- **Вход**: `(42, 7, 19, 99, 3, 58, 12)`
- **Выход**:
  ```text
  Отсортированный кортеж: (99, 58, 42, 19, 12, 7, 3)
  Первый элемент (максимум): 99
  Последний элемент (минимум): 3
  ```

### Задание 2.1. Проверка надёжности пароля `is_password_good`

#### 1. Условие
Написать функцию `is_password_good(password)`, возвращающую `True`, если пароль надежный, и `False` иначе.  
Критерии надежности:
- Длина не менее 10 символов;
- Как минимум одна заглавная буква;
- Как минимум одна строчная буква.  
Использовать обработку исключений `try / finally`.

#### 2. Объяснение логики
- Проверка длины: `len(password) >= 10`.
- Проверка наличия хотя бы одной большой буквы: генератор `any(c.isupper() for c in password)`. Функция `any` сразу возвращает `True`, как только встречает первую заглавную букву.
- Проверка наличия строчной буквы: `any(c.islower() for c in password)`.
- Блок `finally`: блок, который выполняется процессором всегда, даже если в процессе произошла ошибка. В нем фиксируется завершение валидации.

#### 3. Код решения
```python
def is_password_good(password: str) -> bool:
    try:
        if not isinstance(password, str):
            raise TypeError("Пароль должен быть строкового типа.")

        len_ok = len(password) >= 10
        has_upper = any(c.isupper() for c in password)
        has_lower = any(c.islower() for c in password)

        return len_ok and has_upper and has_lower
    finally:
        # Гарантированное выполнение
        pass
```

#### 4. Пример работы
- `"Secret2026"` $\rightarrow$ `False` (длина 10 не достигнута, всего 10? `'Secret2026'` — длина 10, но нет спецсимвола/проверяем: `len=10`, `S` — заглавная, `e` — строчная $\rightarrow$ `True`).
- `"pass"` $\rightarrow$ `False` (слишком короткий).
- `"ALLUPPERCASE123"` $\rightarrow$ `False` (нет строчных букв).

### Задание 2.2. Универсальная функция обработки разных типов данных

#### 1. Условие
Написать функцию с одним аргументом, поведение которой зависит от переданного типа:
- **Кортеж (`tuple`)**: посчитать суммарную длину всех слов внутри него.
- **Список (`list`)**: найти сумму элементов после первого отрицательного числа; удалить все повторяющиеся элементы.
- **Число (`int`)**: посчитать количество чётных цифр.
- **Строка (`str`)**: найти сумму всех чисел, содержащихся в строке.

#### 2. Объяснение логики
- **Кортеж**: фильтруем строковые элементы `isinstance(w, str)` и складываем их длины: `sum(len(w) ...)`.
- **Список**:
  - Ищем индекс первого элемента, который $< 0$. Если отрицательное число есть на позиции `idx`, то берем срез элементов после него `lst[idx + 1:]` и суммируем `sum()`.
  - Удаление дубликатов: стандартная конструкция `list(dict.fromkeys(lst))` удаляет повторы и строго сохраняет порядок элементов.
- **Число**: берем цифры числа по модулю `abs(num)` и считаем те, у которых `digit % 2 == 0`.
- **Строка**: регулярное выражение `re.findall(r'-?\d+', text)` находит все целые числа (включая отрицательные) внутри любого текста, затем они переводятся в `int` и суммируются.

#### 3. Код решения
```python
import re

def process_data(data):
    try:
        if isinstance(data, tuple):
            # Суммарная длина всех слов
            return sum(len(w) for w in data if isinstance(w, str))

        elif isinstance(data, list):
            # Сумма после первого отрицательного
            neg_idx = -1
            for i, val in enumerate(data):
                if isinstance(val, (int, float)) and val < 0:
                    neg_idx = i
                    break
            tail_sum = sum(data[neg_idx + 1:]) if neg_idx != -1 else 0
            # Удаление дубликатов с сохранением порядка
            unique_list = list(dict.fromkeys(data))
            return {"sum_after_negative": tail_sum, "unique_list": unique_list}

        elif isinstance(data, int):
            # Количество четных цифр
            return sum(1 for ch in str(abs(data)) if int(ch) % 2 == 0)

        elif isinstance(data, str):
            # Сумма всех чисел в строке
            nums = [int(m) for m in re.findall(r'-?\d+', data)]
            return sum(nums)

        else:
            raise TypeError(f"Неподдерживаемый тип данных: {type(data)}")
    except Exception as err:
        return f"Ошибка: {err}"
```

#### 4. Пример работы
- **Кортеж** `("яблоко", 10, "банан")` $\rightarrow$ $6 + 5 = 11$.
- **Список** `[4, 2, -3, 5, 1, 5, 2]` $\rightarrow$ первое отрицательное `-3`, после него элементы `5, 1, 5, 2` (сумма = $13$); уникальный список: `[4, 2, -3, 5, 1]`.
- **Число** `24679` $\rightarrow$ чётные цифры `2, 4, 6` (кол-во = 3).
- **Строка** `"Купили 3 билета по 15 рублей и 2 подарка"` $\rightarrow$ числа `3, 15, 2`, их сумма = $20$.

### Задание 2.3. Перестановка столбцов двумерного массива (матрицы)

#### 1. Условие
Дан двумерный массив $n \times m$ и два индекса столбцов $i$ и $j$. Поменять местами столбцы $i$ и $j$ и вывести результат.

#### 2. Объяснение логики
- Матрица в Python представляется как список списков (где каждый вложенный список — это строка).
- Чтобы поменять местами два столбца, нужно пройти по **каждой строке** матрицы и в этой строке обменять местами элементы с индексами $i$ и $j$.
- Обмен значений в Python выполняется элегантно через множественное присваивание за одну операцию без временной переменной:  
  `row[i], row[j] = row[j], row[i]`
- Программа проверяет, не выходят ли индексы $i$ и $j$ за границы допустимых номеров столбцов ($0 \le i < m$).

#### 3. Код решения
```python
def swap_columns(matrix: list, i: int, j: int) -> list:
    try:
        n = len(matrix)
        m = len(matrix[0])

        if not (0 <= i < m and 0 <= j < m):
            raise IndexError(f"Индексы столбцов должны быть в диапазоне от 0 до {m-1}.")

        # Создаем копию матрицы
        new_matrix = [row.copy() for row in matrix]
        for row in new_matrix:
            row[i], row[j] = row[j], row[i]

        return new_matrix
    except Exception as err:
        raise err
```

#### 4. Пример работы
- **Исходная матрица $3 \times 3$**:
  ```text
  [1, 2, 3]
  [4, 5, 6]
  [7, 8, 9]
  ```
- **Замена столбцов**: $i = 0$ и $j = 2$ (первый и третий).
- **Результат**:
  ```text
  [3, 2, 1]
  [6, 5, 4]
  [9, 8, 7]
  ```

### Задание 2.4. Демонстрация работы try / except / else / finally

#### 1. Условие
Написать программу, наглядно демонстрирующую работу синтаксической конструкции `try / except / else / finally`.

#### 2. Объяснение логики
- `try`: защищенный блок, где находится код, в котором потенциально может возникнуть ошибка (например, деление на ноль или открытие несуществующего файла).
- `except`: перехватывает указанную ошибку и выполняет аварийный сценарий вместо аварийного падения программы.
- `else`: выполняется **только тогда**, когда в блоке `try` всё прошло успешно и никаких ошибок не было.
- `finally`: выполняется **всегда и гарантированно** (независимо от того, была ошибка или нет). Используется для освобождения ресурсов (закрытия файлов, сетевых соединений).

#### 3. Код решения
```python
def safe_divide_and_log(a: float, b: float):
    print(f"\n--- Операция: {a} / {b} ---")
    file_handle = None
    try:
        print("[try]: выполняем деление...")
        result = a / b
    except ZeroDivisionError as err:
        print(f"[except]: Перехвачена ошибка деления на ноль ({err})")
        result = None
    else:
        print(f"[else]: Ошибок не возникло, результат = {result}")
    finally:
        print("[finally]: Завершение блока, очистка ресурсов.")
    return result
```

#### 4. Пример работы
- **Сценарий 1 (Успех: $10 / 2$)**:
  - `[try]`: деление выполнено.
  - `[else]`: результат = 5.0.
  - `[finally]`: ресурсы закрыты.
- **Сценарий 2 (Ошибка: $10 / 0$)**:
  - `[try]`: возникло `ZeroDivisionError`.
  - `[except]`: ошибка перехвачена, выведено предупреждение.
  - `[finally]`: ресурсы закрыты.

### Задание 3.1. Пользовательский класс `CustomList`

#### 1. Условие
Создать класс `List` (список), в котором реализовать не менее 5 методов для работы со списком.

#### 2. Объяснение логики
Класс инкапсулирует внутри себя стандартный список `self._data` и предоставляет удобный расширенный API:
1. `append(item)` — добавление элемента в конец;
2. `remove(item)` — безопасное удаление первого вхождения;
3. `reverse()` — переворот элементов;
4. `sort(reverse)` — сортировка по возрастанию или убыванию;
5. `min_max()` — быстрое получение кортежа `(минимум, максимум)`;
6. `unique()` — получение списка без повторяющихся элементов;
7. `filter_by(func)` — фильтрация элементов по произвольному условию (лямбда-функции);
8. `frequency_dict()` — частотный анализ (сколько раз каждый элемент встречается).

#### 3. Код решения
```python
class CustomList:
    def __init__(self, initial_data=None):
        self._data = list(initial_data) if initial_data else []

    def append(self, item):
        self._data.append(item)

    def remove(self, item) -> bool:
        if item in self._data:
            self._data.remove(item)
            return True
        return False

    def reverse(self):
        self._data.reverse()

    def sort(self, reverse: bool = False):
        self._data.sort(reverse=reverse)

    def min_max(self):
        if not self._data:
            return None, None
        return min(self._data), max(self._data)

    def unique(self):
        return list(dict.fromkeys(self._data))

    def filter_by(self, predicate):
        return [x for x in self._data if predicate(x)]

    def frequency_dict(self):
        freq = {}
        for x in self._data:
            freq[x] = freq.get(x, 0) + 1
        return freq

    def __repr__(self):
        return f"CustomList({self._data})"
```

#### 4. Пример работы
```python
my_list = CustomList([5, 2, 8, 2, 9, 1, 5])
my_list.unique()         # -> [5, 2, 8, 9, 1]
my_list.min_max()        # -> (1, 9)
my_list.filter_by(lambda x: x > 4)  # -> [5, 8, 9, 5]
my_list.frequency_dict() # -> {5: 2, 2: 2, 8: 1, 9: 1, 1: 1}
```

### Задание 3.4. Методы экземпляра, методы класса и статические методы

#### 1. Условие
Придумать класс самостоятельно, реализовать в нем методы трех типов: методы экземпляра класса, статические методы (`@staticmethod`) и методы класса (`@classmethod`).

#### 2. Объяснение логики
Разработан класс `StudentAccount` (студенческий профиль):
1. **Методы экземпляра (`self`)**:
   Обычные методы, которые работают с данными конкретного студента (его имя, оценки).  
   *Пример*: `add_grade(grade)` добавляет оценку, `get_average()` вычисляет средний балл этого студента.
2. **Методы класса (`@classmethod`, принимает `cls`)**:
   Работают не с одним объектом, а с классом в целом. Используются как альтернативные фабричные конструкторы.  
   *Пример*: `from_string(cls, "Иванов И.И., 351002, 8.5")` принимает одну текстовую строку (например, из базы данных или CSV-файла), сам разбирает ее на части и возвращает готовый созданный объект студента.
3. **Статические методы (`@staticmethod`, без `self` и `cls`)**:
   Утилитарные функции, которые логически относятся к теме класса, но не зависят от состояния объектов.  
   *Пример*: `validate_student_id(id_str)` проверяет регулярным выражением, состоит ли номер студенческого из 6 цифр; `convert_grade_to_ects(grade)` переводит 10-балльную оценку в буквенную шкалу ECTS (A, B, C, D, F).

#### 3. Код решения
```python
class StudentAccount:
    def __init__(self, name: str, group: str, average_grade: float):
        self.name = name
        self.group = group
        self.average_grade = average_grade

    # 1. Метод экземпляра: использует self
    def has_scholarship(self) -> bool:
        return self.average_grade >= 8.0

    # 2. Метод класса: альтернативный конструктор из строки
    @classmethod
    def from_string(cls, csv_line: str):
        parts = [p.strip() for p in csv_line.split(",")]
        name = parts[0]
        group = parts[1]
        grade = float(parts[2])
        return cls(name, group, grade)

    # 3. Статический метод: независимая утилита
    @staticmethod
    def convert_grade_to_ects(grade: float) -> str:
        if grade >= 9.0: return "A"
        elif grade >= 8.0: return "B"
        elif grade >= 7.0: return "C"
        elif grade >= 6.0: return "D"
        else: return "F"
```

#### 4. Пример работы
```python

s1.has_scholarship()  # -> True (метод экземпляра)

# Создание через фабричный метод класса
s2 = StudentAccount.from_string("Петров П. П., 351001, 7.4")

# Вызов статического метода без создания объектов
StudentAccount.convert_grade_to_ects(9.2)  # -> 'A'
```
