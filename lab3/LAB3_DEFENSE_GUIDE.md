# Глава 1. Генерация данных, масштабирование и зачем нужен столбец единиц X_b (Bias)

## 1.1. Построчный разбор генератора `make_regression`
В соответствии с требованиями лабораторной работы, исследование алгоритмов оптимизации проводится на контролируемом синтетическом датасете множественной линейной регрессии.

```python
X_raw, y_raw, coef_true = make_regression(
    n_samples=1000,
    n_features=2,
    noise=10.0,
    coef=True,
    random_state=42
)
```

### Разбор каждого параметра и его физико-математического смысла:
1. `n_samples=1000` ($\ell = 1000$)  
   Количество наблюдений (строк) в обучающей выборке. Выборка из 1000 объектов репрезентативна для статистической оценки матожиданий и дисперсий по закону больших чисел Чебышёва.
2. `n_features=2` ($d = 2$)  
   Количество независимых входных признаков (факторов $x_1$ и $x_2$). Двумерное признаковое пространство выбрано для возможности прямой двумерной и трехмерной визуализации изолиний функции потерь (Contour Plots) и физической траектории движения векторов весов $(w_1, w_2)$.
3. `noise=10.0` ($\sigma_{\text{noise}} = 10.0$)  
   **Фундаментальный параметр задачи!** Функция добавляет к истинной линейной комбинации некоррелированный аддитивный гауссов шум:
   $$\varepsilon_i \sim \mathcal{N}(0, \sigma^2), \quad \text{где } \sigma = 10.0$$
   Истинный закон формирования целевой переменной в генераторе имеет вид:
   $$y_i = w_1^* x_{i1} + w_2^* x_{i2} + \varepsilon_i$$
   **Критический теоретический вывод для защиты:**  
   Поскольку дисперсия неустранимого шума генератора равна:
   $$\text{Var}(\varepsilon) = \sigma^2 = 10.0^2 = \mathbf{100.0}$$
   теоретический предел качества (минимально возможная среднеквадратичная ошибка $\text{MSE}$) для любой, даже абсолютно идеальной модели регрессии, строго ограничен снизу:
   $$\text{MSE}_{\min} \ge \sigma^2 = \mathbf{100.0}$$
   Попытка алгоритма оптимизации получить $\text{MSE} \ll 100$ означала бы грубую подгонку под конкретную реализацию случайного белого шума (Overfitting / переобучение).
4. `coef=True`  
   Заставляет функцию вернуть кортеж из трех элементов, включая истинный вектор весов генератора `coef_true` (в нашем запуске с `seed=42`: $w_1 \approx 39.47$, $w_2 \approx 6.90$), относительно которого проверяется точность сходимости градиентного спуска.
5. `random_state=42`  
   Фиксирует начальное состояние псевдослучайного генератора (PRNG). Обеспечивает 100% повторяемость, идемпотентность и совпадение всех численных значений у студента и преподавателя на защите.

## 1.2. Зачем обязательно масштабировать признаки перед градиентным спуском?

```python
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X_raw)
```

В сырых данных признаки $x_1$ и $x_2$ могут обладать разной дисперсией. Если один признак имеет размах $[0, 1000]$, а второй $[0, 1]$, то матрица вторых производных (Гессиан $H = \frac{2}{\ell} X^T X$) квадратичной функции потерь $\text{MSE}$ имеет сильно различающиеся собственные значения:
$$\lambda_{\max} \gg \lambda_{\min}$$
Отношение максимального собственного значения к минимальному называется **числом обусловленности (Condition Number)**:
$$\kappa(H) = \frac{\lambda_{\max}}{\lambda_{\min}} \gg 1$$

### Что происходит с геометрией функции потерь:
1. **Без масштабирования ($\kappa \gg 1$):**  
   Линии уровня функции потерь $Q(w)$ представляют собой сверхвытянутые, сплюснутые эллиптические «овраги». Градиент $\nabla Q(w)$ по определению направлен строго перпендикулярно касательной к изолинии. В вытянутом эллипсе вектор градиента указывает почти поперёк оврага, а не в сторону истинного глобального минимума на дне! В результате градиентный спуск начинает совершать хаотичные зигзагообразные скачки от одного борта оврага к другому, требуя тысячи итераций для продвижения к цели.
2. **После `StandardScaler` ($\mu = 0, \sigma = 1, \kappa \approx 1$):**  
   Дисперсии признаков выравниваются. Число обусловленности стремится к 1. Линии уровня из эллипсов превращаются в **идеальные концентрические окружности (сферы в $\mathbb{R}^d$)**.  
   В окружности радиус-вектор в любой точке строго коллинеарен направлению на центр! Вектор антиградиента $-\nabla Q$ указывает **в точности на точку глобального оптимума $w^*$**. Сходимость ускоряется в десятки раз по кратчайшей прямой траектории.

## 1.3. Архитектура столбца единиц `X_b` (Bias / Свободный член $w_0$)

```python
X_b = np.c_[np.ones(len(X_scaled)), X_scaled]
```

### Разбор синтаксиса `np.c_`:
`np.c_` — это специальный оператор конкатенации библиотеки NumPy по колонкам (Column-wise stacking).
- `np.ones(len(X_scaled))` создает одномерный массив длины 1000, заполненный числами `1.0`: вектор размерности `(1000,)`.
- `X_scaled` — матрица признаков размерности `(1000, 2)`.
- Оператор `np.c_` преобразует вектор единиц в вертикальный столбец `(1000, 1)` и приклеивает его слева к матрице `(1000, 2)`.
- Результирующая расширенная матрица плана `X_b` получает размерность:
  $$\text{shape}(X_b) = (1000, 3)$$

### Математический смысл: почему первая колонка должна быть из единиц?
Уравнение многомерной линейной регрессии со свободным членом (сдвигом прямой / интерцептом) имеет вид:
$$\hat{y}_i = w_0 + w_1 x_{i1} + w_2 x_{i2}$$
Обратите внимание: вес $w_0$ стоит изолированно, он не умножается ни на какой входной признак.  
Чтобы записать всю систему уравнений для 1000 студентов в едином компактном матричном виде:
$$\hat{y} = X_b \cdot w$$
где вектор весов имеет размерность $3 \times 1$:
$$w = \begin{bmatrix} w_0 \\ w_1 \\ w_2 \end{bmatrix}$$
мы искусственно вводим фиктивный нулевой признак $x_{i0} \equiv 1.0$.

### Пошаговый числовой расчет матричного умножения для первой строки датасета:
Возьмем первую строку расширенной матрицы $X_b$ (студент с индексом 0):
$$x_0^T = \begin{bmatrix} 1.0 & -0.208407 & 0.088453 \end{bmatrix}$$
Выполним умножение строки на вектор весов $w$:
$$\hat{y}_0 = x_0^T w = \begin{bmatrix} 1.0 & -0.208407 & 0.088453 \end{bmatrix} \begin{bmatrix} w_0 \\ w_1 \\ w_2 \end{bmatrix} = w_0 \cdot 1.0 + w_1 \cdot (-0.208407) + w_2 \cdot (0.088453)$$

**Вывод:** умножение $w_0 \times 1.0$ гарантирует, что $w_0$ прибавляется как константный аддитивный сдвиг ко всем прогнозам выборки. Без столбца единиц прямая регрессии была бы жестко прибита гвоздями к началу координат $(0, 0, 0)$ и не смогла бы подняться или опуститься по вертикали вдоль оси $Y$.

# Глава 2. Линейная регрессия, функция потерь MSE и Пакетный градиентный спуск (BGD)

## 2.1. Построчный разбор функции вычисления ошибки `compute_mse`

```python
def compute_mse(X: np.ndarray, y: np.ndarray, w: np.ndarray) -> float:
    """Вычисляет среднеквадратичную ошибку (Mean Squared Error)."""
    residuals = X @ w - y
    return float(np.mean(residuals ** 2))
```

### Разбор механики каждой строчки:
1. `residuals = X @ w - y`  
   - Оператор `@` в Python 3.5+ означает **матричное умножение**.  
     Матрица плана `X` размерности `(1000, 3)` умножается на одномерный вектор весов `w` размерности `(3,)`.
     $$\text{shape: } (1000, 3) \times (3,) \longrightarrow (1000,)$$
     Результатом является вектор модельных прогнозов $\hat{y} = X w$.
   - Из вектора прогнозов поэлементно вычитается вектор фактических ответов `y` размерности `(1000,)`.  
     Получается вектор невязок (остатков) $e_i = \hat{y}_i - y_i$.
2. `np.mean(residuals ** 2)`  
   - `residuals ** 2` возводит каждую ошибку в квадрат: $e_i^2 = (\hat{y}_i - y_i)^2$.
   - `np.mean(...)` вычисляет выборочное среднее арифметическое: делит сумму квадратов на общее число объектов $\ell = 1000$:
     $$Q(w, X) = \text{MSE}(w) = \frac{1}{\ell} \sum_{i=1}^\ell (x_i^T w - y_i)^2 = \frac{1}{\ell} \|Xw - y\|_2^2$$
3. `float(...)`  
   Преобразует тип `numpy.float64` в стандартный питоновский примитив `float` для чистой сериализации в JSON.

## 2.2. Математический вывод градиента: откуда взялась двойка и матрица $X^T$?

> **Один из главных теоретических вопросов преподавателя:**  
> *«Возьмите маркер и выведите формулу градиента функции потерь $\nabla Q(w)$. Объясните, почему там стоит коэффициент 2 и откуда берется транспонированная матрица $X^T$?»*

### Вывод на пальцах по правилу дифференцирования сложной функции:
Распишем функцию потерь для одного конкретного $i$-го объекта выборки:
$$Q_i(w) = (x_i^T w - y_i)^2$$
Вспомним базовое правило производной из математического анализа:
$$(f(u))^2 \Big|'_u = 2 \cdot f(u) \cdot f'(u)$$
Здесь внешней функцией является возведение в квадрат $(\dots)^2$, а внутренней функцией — линейная ошибка $f(w) = (x_i^T w - y_i)$.

1. **Берем производную по вектору весов $w$:**
   $$\nabla_w Q_i(w) = 2 \cdot (x_i^T w - y_i) \cdot \nabla_w (x_i^T w - y_i)$$
2. **Чему равна производная от внутренней части $(x_i^T w - y_i)$ по вектору $w$?**
   Вектор $y_i$ — это константа (производная 0).  
   Производная от скалярного произведения $x_i^T w = x_{i0} w_0 + x_{i1} w_1 + x_{i2} w_2$ по вектору $w$ в точности равна самому вектору признаков $x_i$:
   $$\nabla_w (x_i^T w) = x_i$$
3. **Получаем градиент по $i$-му объекту:**
   $$\nabla_w Q_i(w) = 2 \cdot (x_i^T w - y_i) \cdot x_i$$
   Вот откуда взялась **двойка** — это показатель степени квадрата ошибки!

4. **Суммируем по всей выборке из $\ell$ объектов:**
   $$\nabla Q(w, X) = \frac{1}{\ell} \sum_{i=1}^\ell \nabla_w Q_i(w) = \frac{2}{\ell} \sum_{i=1}^\ell x_i (x_i^T w - y_i)$$

5. **Переход к матричному виду (откуда взялась $X^T$):**  
   Заметим, что разность $(x_i^T w - y_i)$ — это $i$-я компонента вектора ошибок $(Xw - y)$ длины $\ell$.  
   Вектор $x_i$ — это $i$-я **строка** исходной матрицы данных $X$.  
   Чтобы умножить столбцы признаков на вектор ошибок длины $\ell$, строки матрицы $X$ нужно перевернуть в столбцы, то есть **транспонировать матрицу**:
   $$\sum_{i=1}^\ell x_i (Xw - y)_i = X^T \cdot (Xw - y)$$
   
   Проверим согласованность матричных размерностей:
   $$\underbrace{X^T}_{(d \times \ell)} \cdot \underbrace{(Xw - y)}_{(\ell \times 1)} = \underbrace{\nabla Q}_{(d \times 1)}$$
   Размерности сошлись идеально! Итоговая векторная формула градиента:
   $$\nabla Q(w, X) = \frac{2}{\ell} X^T (Xw - y)$$

## 2.3. Построчный разбор функции `batch_gradient_descent` с матричными размерностями

```python
def batch_gradient_descent(X: np.ndarray, y: np.ndarray, eta: float = 0.05,
                           eps: float = 1e-5, max_iter: int = 1000):
    l, d = X.shape
    w = np.zeros(d, dtype=float)
    w_history = [w.copy()]
    mse_history = [compute_mse(X, y, w)]
    diff_norms = []
    converged = False

    for k in range(1, max_iter + 1):
        grad = (2.0 / l) * (X.T @ (X @ w - y))
        w_new = w - eta * grad
        diff_norm = float(np.linalg.norm(w_new - w))
        diff_norms.append(diff_norm)

        w = w_new
        w_history.append(w.copy())
        mse_history.append(compute_mse(X, y, w))

        if diff_norm < eps:
            converged = True
            break
```

### Построчная расстановка размерностей и назначение переменных:
1. `l, d = X.shape` $\longrightarrow$ `l = 1000` (число строк/объектов), `d = 3` (число столбцов/весов).
2. `w = np.zeros(d, dtype=float)` $\longrightarrow$ вектор начальных весов $w^{(0)} = [0.0, 0.0, 0.0]$ размерности `(3,)`.
3. `X @ w`: умножение `(1000, 3) @ (3,) -> (1000,)` — вектор предсказаний $\hat{y}$.
4. `(X @ w - y)`: вычитание `(1000,) - (1000,) -> (1000,)` — вектор невязок ошибок.
5. `X.T @ (...)`: умножение транспонированной матрицы `(3, 1000) @ (1000,) -> (3,)` — вектор суммарного взвешенного градиента.
6. `grad = (2.0 / l) * (...)`: скалярное умножение на $\frac{2}{1000} = 0.002$. Градиент `grad` имеет размерность `(3,)`.
7. `w_new = w - eta * grad`:  
   **ФОРМУЛА ИЗ ФОТО 1 ЗАДАНИЯ:**  
   $$w^k = w^{k-1} - \eta_k \nabla Q(w^{k-1}, X)$$
   Вектор весов делает шаг величиной $\eta = 0.05$ строго против направления градиента (в сторону наискорейшего спада функции потерь).
8. `diff_norm = float(np.linalg.norm(w_new - w))`:  
   Евклидова норма (длина) вектора смещения весов за текущий шаг:
   $$\|\Delta w\|_2 = \|w^k - w^{k-1}\|_2 = \sqrt{(w_0^k - w_0^{k-1})^2 + (w_1^k - w_1^{k-1})^2 + (w_2^k - w_2^{k-1})^2}$$
9. `if diff_norm < eps: break`:  
   **ФОРМУЛА ИЗ ФОТО 2 ЗАДАНИЯ:**  
   $$\|w^k - w^{k-1}\| < \varepsilon, \quad \text{где } \varepsilon = 10^{-5}$$
   Если за один шаг алгоритма суммарное изменение всех весов по теореме Пифагора стало меньше одной стотысячной ($10^{-5}$), мы гарантированно пришли на плоское дно параболоида ошибки. Цикл останавливается.

**Шаг 4: Расчет градиента $\nabla Q = \frac{2}{3} X^T e$:**
$$\nabla Q_0 = \frac{2}{3} \times (1.0 \times 14.9969 + 1.0 \times 12.6781 + 1.0 \times (-17.7755)) = \frac{2}{3} \times 9.8995 \approx \mathbf{+6.60}$$
$$\nabla Q_1 = \frac{2}{3} \times ((-0.2084) \times 14.9969 + (-0.0563) \times 12.6781 + 0.1220 \times (-17.7755)) = \frac{2}{3} \times (-6.0077) \approx \mathbf{-4.01}$$
$$\nabla Q_2 = \frac{2}{3} \times (0.0885 \times 14.9969 + 0.0595 \times 12.6781 + 0.3036 \times (-17.7755)) = \frac{2}{3} \times (-3.3151) \approx \mathbf{-2.21}$$
$$\nabla Q = \begin{bmatrix} +6.60 \\ -4.01 \\ -2.21 \end{bmatrix}$$
**Шаг 5: Обновление весов $w^{(1)} = w^{(0)} - 0.05 \cdot \nabla Q$:**
$$w_0^{(1)} = 0.0 - 0.05 \times (+6.60) = \mathbf{-0.33}$$
$$w_1^{(1)} = 0.0 - 0.05 \times (-4.01) = \mathbf{+0.20}$$
$$w_2^{(1)} = 0.0 - 0.05 \times (-2.21) = \mathbf{+0.11}$$
**Шаг 6: Проверка условия останова:**
$$\|\Delta w\|_2 = \sqrt{(-0.33)^2 + 0.20^2 + 0.11^2} = \sqrt{0.1089 + 0.0400 + 0.0121} = \sqrt{0.1610} \approx \mathbf{0.4015}$$
Так как $0.4015 \ge 10^{-5}$, цикл продолжается дальше!

## 2.5. Аналитическое МНК-решение (Normal Equation) и вычислительная сложность

```python
w_analytical = np.linalg.inv(X_b.T @ X_b) @ X_b.T @ y_raw
```

### Строгий математический вывод формулы:
Чтобы найти глобальный минимум квадратичной функции потерь, приравняем её градиент к нулевому вектору:
$$\nabla Q(w^*) = \mathbf{0}$$
$$\frac{2}{\ell} X^T (X w^* - y) = \mathbf{0}$$
Разделим на $\frac{2}{\ell}$ и раскроем скобки:
$$X^T X w^* - X^T y = \mathbf{0}$$
$$X^T X w^* = X^T y$$
Умножим обе части уравнения слева на обратную матрицу $(X^T X)^{-1}$:
$$\underbrace{(X^T X)^{-1} (X^T X)}_{I} w^* = (X^T X)^{-1} X^T y$$
$$w^* = (X^T X)^{-1} X^T y$$

### Почему МНК неприменим в Big Data и зачем нужен градиентный спуск?
Посмотрим на операцию обратной матрицы `np.linalg.inv(X.T @ X)`:
- Матрица $X^T X$ имеет размерность $(d \times d)$, где $d$ — число признаков.
- Точное вычисление обратной матрицы методом Гаусса или разложением Холецкого имеет кубическую асимптотическую сложность:
  $$\mathcal{O}(d^3)$$
- Если $d = 2$, обращение матрицы требует $2^3 = 8$ элементарных операций (выполняется за наносекунды).
- Если $d = 100\,000$ (обработка текста, Bag-of-Words, биоинформатика, генетика):
  $$d^3 = (10^5)^3 = 10^{15} \text{ операций}$$
  Для такого расчета потребуется терабайты оперативной памяти и недели работы суперкомпьютера!
- **Градиентный спуск** вообще **не обращает матрицы**! На каждом шаге он выполняет только умножение матрицы на вектор со сложностью $\mathcal{O}(\ell \cdot d)$. При 100 итерациях это всего лишь $100 \times 1000 \times 3 \approx 3 \times 10^5$ операций (миллисекунды). Поэтому градиентный спуск является базовым двигателем всего современного машинного обучения и нейросетей.

# Глава 3. Эксперименты со скоростью обучения (Learning Rate eta)

## 3.1. Роль гиперпараметра темпа обучения $\eta$ в оптимизации
**Темп обучения (Learning Rate $\eta$)** — это скалярный масштабирующий множитель перед вектором градиента в формуле обновления весов:
$$w^k = w^{k-1} - \eta \cdot \nabla Q(w^{k-1})$$
Он определяет физическую длину шага, который делает модель в пространстве параметров на каждой итерации. Градиент $\nabla Q$ задает только **направление** наискорейшего подъема (а со знаком минус — спада), но ничего не знает о том, **как далеко** нужно идти.

В лабораторной работе протестирована сетка из 5 значений темпа обучения:
$$\eta \in \{0.001, 0.01, 0.05, 0.1, 0.5\}$$
при фиксированном пороге останова $\varepsilon = 10^{-5}$ и лимите в 300 итераций.

---

## 3.2. Математический анализ поведения алгоритма при различных $\eta$

```python
etas = [0.001, 0.01, 0.05, 0.1, 0.5]
for eta_val in etas:
    res = batch_gradient_descent(X_b, y_raw, eta=eta_val, eps=1e-5, max_iter=300)
```

### 1. $\eta = 0.001$ (Сверхмалый шаг — недолет / Slow Convergence)
- **Результат:** за 300 шагов алгоритм **не успел сойтись** (`converged = False`, выполнил все 300 итераций из 300).
- **Математика процесса:** Шаг весов крошечный: $\Delta w = 0.001 \times \nabla Q$. Модель передвигается «микроскопическими шажками». Норма разности весов к 300-й итерации всё ещё превышает порог $\varepsilon = 10^{-5}$. Чтобы достичь минимума, такому оптимизатору потребуется более 1500–2000 шагов. В реальных задачах это означает нерациональный перерасход вычислительного времени и электроэнергии GPU.

### 2. $\eta = 0.01$ (Умеренный консервативный шаг)
- **Результат:** сходимость за **~220 итераций**.
- **Математика процесса:** Уверенное, гладкое, монотонное снижение функции потерь без риска вылета за пределы долины.

### 3. $\eta = 0.05$ (Оптимальный темп обучения)
- **Результат:** сходимость за ровно **124 итерации** с идеальной точностью ($\|w_{\text{BGD}} - w^*\| = 8.41 \times 10^{-5}$).
- **Математика процесса:** Достигнут идеальный баланс между скоростью продвижения вдоль градиента и устойчивостью шага.

### 4. $\eta = 0.1$ (Агрессивный темп обучения)
- **Результат:** сходимость всего за **~65 итераций**.
- **Математика процесса:** Минимальное количество шагов до минимума. Однако при приближении к дну параболоида крупный шаг вызывает микроколебания вокруг точки оптимума, пока градиент естественно не затухнет.

## 3.3. КРИТИЧЕСКИЙ ВОПРОС ЗАЩИТЫ: Почему при $\eta = 0.5$ алгоритм перестает нормально сходиться (Осцилляции и перелет)?

> **Любимый вопрос преподавателя на засыпку:**  
> *«Почему мы не можем поставить $\eta = 0.5$ или $\eta = 1.0$, чтобы добежать до минимума за 2 шага? Докажите математически на простой параболе, что происходит при большом шаге!»*

### Строгое одномерное математическое доказательство:
Рассмотрим простейшую одномерную квадратичную функцию потерь:
$$f(w) = w^2$$
Её истинный глобальный минимум находится в точке $w^* = 0$.  
Найдем аналитическую производную:
$$f'(w) = \frac{d}{dw}(w^2) = 2w$$

Запишем один шаг градиентного спуска из произвольной точки $w^{k-1}$:
$$w^k = w^{k-1} - \eta \cdot f'(w^{k-1}) = w^{k-1} - \eta \cdot (2 w^{k-1})$$
Вынесем $w^{k-1}$ за скобки:
$$w^k = w^{k-1} \cdot (1 - 2\eta)$$

Поведение веса $w^k$ на каждом шаге определяется величиной множителя сжатия:
$$q = |1 - 2\eta|$$

### Разбор всех режимов множителя $q$:
1. **Режим сходимости ($0 < \eta < 1.0$):**  
   - При $\eta = 0.1 \longrightarrow q = |1 - 0.2| = 0.8 < 1$.  
     Вес монотонно стягивается в 0: $w^k = 0.8^k \cdot w^0 \longrightarrow 0$.
   - При $\eta = 0.5 \longrightarrow q = |1 - 1.0| = 0.0$.  
     Вес попадает в ноль за один шаг.
2. **Режим незатухающих осцилляций ($\eta = 1.0$):**  
   - При $\eta = 1.0 \longrightarrow q = |1 - 2.0| = |-1.0| = 1.0$.  
     $$w^1 = -w^0, \quad w^2 = w^0, \quad w^3 = -w^0 \dots$$
     Алгоритм входит в бесконечный резонанс: он бесконечно прыгает с одной стенки параболы на другую на одинаковую высоту, никогда не опускаясь на дно!
3. **Режим взрывной расходимости ($\eta > 1.0$):**  
   - При $\eta = 1.5 \longrightarrow q = |1 - 3.0| = |-2.0| = 2.0 > 1$.  
     $$w^1 = -2 w^0, \quad w^2 = +4 w^0, \quad w^3 = -8 w^0, \quad w^k = (-2)^k w^0 \longrightarrow \infty$$
     С каждым шагом алгоритм улетает от оптимума всё дальше в бесконечность! В коде это приводит к значениям весов `inf` и переполнению памяти `OverflowError`.

---

### Обобщение на матричный случай (Теорема о константе Липшица $L$):
Для квадратичной функции потерь $\text{MSE}(w) = \frac{1}{\ell} \|Xw - y\|^2$ Гессиан равен:
$$H = \nabla^2 Q(w) = \frac{2}{\ell} X^T X$$
Градиент $\nabla Q$ удовлетворяет условию Липшица с константой $L$, равной максимальному собственному значению матрицы Гессиана:
$$L = \lambda_{\max}(H) = \lambda_{\max}\left(\frac{2}{\ell} X^T X\right)$$
Фундаментальная теорема математической оптимизации гласит:  
**Пакетный градиентный спуск сходится тогда и только тогда, когда темп обучения удовлетворяет строгому неравенству:**
$$\mathbf{0 < \eta < \frac{2}{L}}$$
Для наших стандартизированных данных ($\text{Var}(x_j) \approx 1$) матрица $\frac{1}{\ell} X^T X \approx I$, откуда $L \approx 2 \times 2 = 4$.  
Следовательно, теоретическая критическая граница расходимости:
$$\eta_{\text{critical}} \approx \frac{2}{4} = \mathbf{0.5}$$
Именно поэтому при $\eta = 0.5$ алгоритм балансирует на грани потери устойчивости и испытывает тяжелые осцилляции.

# Глава 4. Стохастический градиентный спуск (SGD) и затухание шага Роббинса–Монро

## 4.1. Принципиальная разница между BGD и SGD

В машинном обучении существует фундаментальный компромисс между точностью направления шага и вычислительной сложностью его расчета.

| Характеристика | Пакетный градиентный спуск (BGD) | Стохастический градиентный спуск (SGD) |
| :--- | :--- | :--- |
| **Объем данных на 1 шаг** | **Вся выборка целиком** ($\ell = 1000$ объектов) | **Ровно 1 случайный объект** ($i \in \{0, \dots, \ell-1\}$) |
| **Вычислительная сложность 1 шага** | $\mathcal{O}(\ell \cdot d)$ (в нашем случае $1000 \times 3 = 3000$ операций) | $\mathcal{O}(d)$ (всего 3 операции умножения) |
| **Относительная скорость шага** | В $1000$ раз медленнее | **В $1000$ раз быстрее и дешевле** |
| **Характер траектории** | Строго гладкая, детерминированная, монотонная | Изломанная, стохастическая, флуктуирующая |
| **Память (RAM)** | Требует загрузки всей матрицы данных в RAM | Достаточно считывать по одной строке с диска (Streaming) |
| **Применимость к Big Data** | Неприменим при терабайтах данных | **Основной стандарт индустрии** для больших данных и нейросетей |

---

## 4.2. Построчный разбор функции `stochastic_gradient_descent`

```python
def stochastic_gradient_descent(X: np.ndarray, y: np.ndarray, eta0: float = 0.05,
                                max_iter: int = 2000, seed: int = 42):
    np.random.seed(seed)
    l, d = X.shape
    w = np.zeros(d, dtype=float)
    w_history = [w.copy()]
    mse_history = [compute_mse(X, y, w)]

    for k in range(1, max_iter + 1):
        idx = np.random.randint(0, l)
        xi = X[idx]
        yi = y[idx]
        grad_i = 2.0 * (xi @ w - yi) * xi
        eta_k = eta0 / (1.0 + 0.001 * k) # затухающий шаг обучения
        w = w - eta_k * grad_i

        w_history.append(w.copy())
        mse_history.append(compute_mse(X, y, w))

    return { ... }
```

### Разбор логики работы алгоритма:
1. `np.random.seed(seed)`  
   Инициализирует генератор случайных чисел. Гарантирует, что последовательность случайно выбираемых объектов будет строго идентичной при каждом перезапуске программы.
2. `idx = np.random.randint(0, l)`  
   Генерирует случайное целое число от $0$ до $\ell - 1$ с равномерным распределением:
   $$P(\text{idx} = i) = \frac{1}{\ell}$$
   **Почему это критически важно:**  
   Благодаря равномерной вероятности математическое ожидание стохастического градиента $\nabla Q_i$ по всем возможным исходам в точности равно истинному полному градиенту по всей выборке:
   $$\mathbb{E}[\nabla Q_i(w)] = \sum_{i=1}^\ell P(\text{idx} = i) \cdot \nabla Q_i(w) = \frac{1}{\ell} \sum_{i=1}^\ell 2(x_i^T w - y_i) x_i = \nabla Q_{\text{BGD}}(w)$$
   В математической статистике это называется **несмещенной оценкой градиента (Unbiased Gradient Estimator)**.
3. `xi = X[idx], yi = y[idx]`  
   Извлекается одна строка признаков $x_i$ длины 3 и один скалярный ответ $y_i$.
4. `grad_i = 2.0 * (xi @ w - yi) * xi`:
   - `xi @ w`: скалярное произведение строки $x_i$ на вектор весов $w$ $\longrightarrow$ скалярный прогноз $\hat{y}_i$;
   - `(xi @ w - yi)`: скалярная ошибка прогноза на данном конкретном объекте;
   - `2.0 * (...) * xi`: скаляр умножается на вектор признаков $x_i$ размерности `(3,)`.  
     Результат `grad_i` — вектор размерности `(3,)`.
5. `eta_k = eta0 / (1.0 + 0.001 * k)`  
   Динамический пересчет темпа обучения на шаге $k$ по схеме затухания.
6. `w = w - eta_k * grad_i`  
   Мгновенное обновление весов по одному объекту.

## 4.3. Теорема Роббинса–Монро: зачем шагу обязательно нужно затухать?

> **Любимый каверзный вопрос преподавателя:**  
> *«Что произойдет, если в SGD оставить постоянный шаг $\eta = \text{const}$? Сойдется ли стохастический спуск в точку глобального минимума? Объясните условия Роббинса–Монро!»*

### В чем проблема SGD с постоянным шагом $\eta = \text{const}$?
Представим, что веса модели каким-то чудом попали в **точный оптимум** $w^* = (1.766, 39.472, 6.897)$.
- В методе **BGD** полный градиент обратится в ноль: $\nabla Q(w^*) = \mathbf{0}$. Шаг станет равен $w^{k} = w^* - \eta \cdot 0 = w^*$. Алгоритм застынет в точке минимума навсегда.
- В методе **SGD** алгоритм берет один случайный объект $x_i$. Из-за наличия в данных случайного шума генератора ($\sigma_{\text{noise}} = 10.0$) истинный ответ $y_i$ никогда не лежит точно на плоскости регрессии:
  $$y_i = x_i^T w^* + \varepsilon_i \implies x_i^T w^* - y_i = -\varepsilon_i \ne 0$$
  Ошибка на объекте равна шуму!  
  Стохастический градиент не равен нулю:
  $$\nabla Q_i(w^*) = -2 \varepsilon_i x_i \ne \mathbf{0}$$
  Если шаг $\eta$ постоянен, модель совершит случайный толчок в сторону от оптимума на величину $\eta \cdot 2 \varepsilon_i x_i$!  
  **Вывод:** при постоянном шаге SGD **никогда не сойдется в точку $w^*$**! Он будет вечно хаотично плясать вокруг минимума в пределах сферы радиуса $R \propto \eta \sigma^2$.

---

### Условия теоремы Роббинса–Монро (1951 г.):
Герберт Роббинс и Саттон Монро доказали, что стохастический процесс сходится к истинному оптимуму с вероятностью 1 (почти наверное, almost surely), **тогда и только тогда, когда последовательность шагов $\eta_k$ удовлетворяет двум условиям:**

$$\mathbf{1) \quad \sum_{k=1}^\infty \eta_k = \infty \qquad \text{и} \qquad 2) \quad \sum_{k=1}^\infty \eta_k^2 < \infty}$$

#### Физический смысл условий:
1. **Первое условие ($\sum \eta_k = \infty$ — сумма шагов бесконечна):**  
   Суммарное расстояние, которое способен пройти алгоритм при необходимости, должно быть бесконечным. Если бы шаги затухали слишком быстро (например, $\eta_k = \frac{1}{2^k}$, где сумма равна 1), алгоритм мог бы «застрять» на полпути к оптимуму, израсходовав весь запас длины шага.
2. **Второе условие ($\sum \eta_k^2 < \infty$ — сумма квадратов сходится):**  
   Дисперсия суммарного стохастического шума, накапливаемая алгоритмом, пропорциональна $\sum \eta_k^2$. Сходимость ряда квадратов гарантирует, что случайные флуктуации со временем полностью подавляются и затухают до строгого нуля.

### Проверка нашей формулы:
В нашем коде используется классическое гиперболическое расписание:
$$\eta_k = \frac{\eta_0}{1 + 0.001 \cdot k}$$
При больших $k$ знаменатель эквивалентен $c \cdot k$.  
- Ряд $\sum_{k=1}^\infty \frac{1}{k} = \infty$ (гармонический ряд, расходится $\rightarrow$ Условие 1 выполнено);
- Ряд $\sum_{k=1}^\infty \frac{1}{k^2} = \frac{\pi^2}{6} < \infty$ (ряд обратных квадратов Эйлера, сходится $\rightarrow$ Условие 2 выполнено).  
**Теорема Роббинса–Монро выполнена строго на 100%!**

# Глава 5. L2-регуляризация (Ridge Regression, Вариант 7) и сравнение с L1 (Lasso)

## 5.1. Зачем нужна регуляризация в машинном обучении?
В классическом методе наименьших квадратов (МНК) алгоритм минимизирует исключительно ошибку аппроксимации обучающей выборки $\text{MSE}(w)$.  
Если входные признаки скоррелированы между собой (мультиколлинеарность) или если объем данных мал, модель сталкивается с проблемой **переобучения (Overfitting)**:
1. Веса $w_j$ раздуваются до огромных положительных и отрицательных величин (например, $w_1 = +100\,000$, а $w_2 = -99\,998$). На обучающей выборке эти гигантские числа взаимно компенсируют друг друга, давая маленькую ошибку.
2. Но стоит подать на вход тестовый объект с крошечным случайным отклонением в признаке $\Delta x_1 = 0.01$, как предсказание улетает на миллион единиц: $\Delta \hat{y} = 100\,000 \times 0.01 = 1000$!
3. Модель теряет **обобщающую способность** и становится гиперчувствительной к шуму.

**Регуляризация** реализует фундаментальный принцип бритвы Оккама:  
*«Среди моделей, одинаково хорошо описывающих данные, наиболее предпочтительной является самая простая — то есть модель с наименьшими по модулю весами».*

---

## 5.2. Функционал качества Варианта 7 (L2-регуляризация / Ridge Regression)

В соответствии с Вариантом 7 (нечетный вариант) к стандартной функции потерь $\text{MSE}$ добавляется **квадратичный штраф за величину евклидовой нормы весов** ($L_2$-штраф Тихонова):

$$Q_{L2}(w, X) = \text{MSE}(w) + \lambda \sum_{j=1}^d w_j^2 = \frac{1}{\ell} \|Xw - y\|_2^2 + \lambda \|w_{1:d}\|_2^2$$

где $\lambda \ge 0$ — гиперпараметр силы регуляризации.
- При $\lambda = 0$ функционал вырождается в стандартный МНК (нет штрафа за сложность).
- При $\lambda \to \infty$ штраф за веса подавляет ошибку данных, заставляя все информативные коэффициенты $w_1, \dots, w_d$ стремиться к нулю.

---

## 5.3. Построчный разбор аналитического решения `ridge_analytical`

```python
def ridge_analytical(X: np.ndarray, y: np.ndarray, l2_lambda: float) -> np.ndarray:
    l, d = X.shape
    I_reg = np.eye(d, dtype=float)
    I_reg[0, 0] = 0.0 # свободный член не регуляризуется
    return np.linalg.inv(X.T @ X + l2_lambda * l * I_reg) @ (X.T @ y)
```

### А. Почему свободный член $w_0$ (bias) КАТЕГОРИЧЕСКИ НЕЛЬЗЯ штрафовать?
Обратите внимание на строчку `I_reg[0, 0] = 0.0`:
Матрица `I_reg` для $d = 3$ имеет вид:
$$I_{\text{reg}} = \begin{bmatrix} \mathbf{0} & 0 & 0 \\ 0 & \mathbf{1} & 0 \\ 0 & 0 & \mathbf{1} \end{bmatrix}$$
На главной диагонали в позиции $[0, 0]$ (соответствующей свободному члену $w_0$) стоит **строгий ноль**.

**Физико-математическая причина:**
1. Вес $w_0$ отвечает за глобальный уровень смещения предсказаний по вертикали:
   $$\hat{y}_i = w_0 + w_1 x_{i1} + w_2 x_{i2}$$
   Если признаки центрированы ($\bar{x} = 0$), то свободный член равен просто среднему значению целевой переменной:
   $$w_0 \approx \mathbb{E}[y]$$
2. Если в данных средний балл за экзамен равен $\bar{y} = 67.24$, а мы накажем модель за величину $w_0^2$, регуляризатор начнет насильно притягивать $w_0$ к нулю. Прямая регрессии опустится вниз к полу, модель начнет систематически занижать прогнозы на 67 баллов для всех студентов!
3. Штрафование $w_0$ приводит к возникновению искусственного системного смещения (**Induced Systematic Bias**). Штрафоваться должны только коэффициенты наклона плоскости $w_1, \dots, w_d$.

---

### Б. Откуда в коде взялось умножение на `l` (`l2_lambda * l * I_reg`)?

> **Глубокий теоретический вопрос преподавателя:**  
> *«В учебниках формула Ridge пишется как $(X^T X + \lambda I)^{-1} X^T y$. Почему у вас в коде стоит `l2_lambda * l * I_reg`? Откуда там взялось число `l = 1000`? Это ошибка?»*

### Доказательство Senior ML Engineer:
**НЕТ, ЭТО НЕ ОШИБКА, А ЕДИНСТВЕННО ВЕРНАЯ МАТЕМАТИЧЕСКАЯ РЕАЛИЗАЦИЯ!**  
Путаница возникает из-за нормировки функции потерь на объем выборки $\ell$.

Распишем строгий функционал, реализованный в нашем коде:
$$Q_{L2}(w) = \frac{1}{\ell} (Xw - y)^T (Xw - y) + \lambda w^T I_{\text{reg}} w$$
Возьмем аналитическую производную по вектору $w$ и приравняем её к нулю:
$$\nabla_w Q_{L2}(w) = \frac{2}{\ell} X^T (Xw - y) + 2 \lambda I_{\text{reg}} w = \mathbf{0}$$
Разделим всё уравнение на 2:
$$\frac{1}{\ell} X^T (Xw - y) + \lambda I_{\text{reg}} w = \mathbf{0}$$
Умножим ВСЁ уравнение на скаляр $\ell = 1000$:
$$X^T (Xw - y) + \lambda \cdot \ell \cdot I_{\text{reg}} w = \mathbf{0}$$
Раскрываем матричные скобки:
$$X^T X w - X^T y + \lambda \ell I_{\text{reg}} w = \mathbf{0}$$
Переносим свободный член $X^T y$ в правую часть и группируем слагаемые при $w$:
$$(X^T X + \lambda \ell I_{\text{reg}}) w = X^T y$$
Умножаем обе части уравнения слева на обратную матрицу:
$$w_{\text{Ridge}} = \mathbf{\left(X^T X + \lambda \ell I_{\text{reg}}\right)^{-1} X^T y}$$

**Вывод:** Множитель $\ell$ обязан стоять перед $\lambda$, потому что ошибка данных в коде делится на число строк $\ell = 1000$ (среднеквадратичная ошибка $\text{MSE}$). Если бы мы не умножили на $\ell$, реальная сила штрафа оказалась бы **в 1000 раз слабее заявленной**, и регуляризация практически не работала бы!

---

### В. Почему добавление $\lambda \ell I'$ гарантирует обратимость матрицы?
Если в выборке есть два одинаковых или линейно зависимых признака, столбцы матрицы $X$ коллинеарны.  
Тогда определитель $\det(X^T X) = 0$, матрица сингулярна и не имеет обратной.

Что происходит при добавлении $\lambda \ell I_{\text{reg}}$:
$$(X^T X + \lambda \ell I_{\text{reg}}) = \begin{bmatrix} \sum x_{i0}^2 & \sum x_{i0} x_{i1} & \dots \\ \sum x_{i1} x_{i0} & \sum x_{i1}^2 + \mathbf{\lambda \ell} & \dots \\ \dots & \dots & \sum x_{id}^2 + \mathbf{\lambda \ell} \end{bmatrix}$$
К диагональным элементам признаков прибавляется строго положительное число $\lambda \ell > 0$.  
По спектральной теореме, собственные значения новой матрицы сдвигаются вправо:
$$\lambda_j(X^T X + \lambda \ell I_{\text{reg}}) = \lambda_j(X^T X) + \lambda \ell \ge \lambda \ell > 0$$
Матрица становится **строго положительно определенной (Strictly Positive Definite)**! Её определитель строго больше нуля, а обратная матрица гарантированно существует при любых, даже абсолютно вырожденных данных. Именно поэтому метод исторически назвали «гребневой регрессией» (Ridge) — добавление гребня высотой $\lambda \ell$ по главной диагонали матрицы.

## 5.5. Сравнение L2 (Ridge) и L1 (Lasso): почему L1 зануляет веса, а L2 — нет?

> **Ключевой фундаментальный вопрос экзамена/защиты:**  
> *«Почему при $\lambda = 1000$ в L2-регуляризации веса стали маленькими ($0.039, 0.007$), но НЕ НУЛЕВЫМИ, а в L1-регуляризации (Lasso) они обратились в СТРОГИЙ НОЛЬ ($0.000000$)? Докажите аналитически и геометрически!»*

---

### Аналитическое доказательство через производные штрафов:

#### 1. Для $L_2$-регуляризации (Ridge):
Штраф равен $R_{L2}(w) = \lambda w_j^2$.  
Найдем частную производную штрафа по весу $w_j$:
$$\frac{\partial R_{L2}}{\partial w_j} = 2 \lambda \cdot w_j$$
Обратите внимание: **производная пропорциональна самой величине веса $w_j$!**
- Когда вес велик ($w_j = 40$), сила сжатия огромна: $2 \times \lambda \times 40 = 80\lambda$. Штраф мощно толкает вес к нулю.
- Но когда вес уменьшился до микроскопической величины ($w_j = 0.001$), сила штрафа падает почти до нуля: $2 \times \lambda \times 0.001 = 0.002\lambda$!  
Около нуля сила сжатия полностью исчезает. Регуляризатор перестает сопротивляться градиенту данных, и вес **никогда не достигает точного нуля**, а лишь асимптотически стремится к нему.

#### 2. Для $L_1$-регуляризации (Lasso):
Штраф равен $R_{L1}(w) = \lambda |w_j|$.  
Найдем частную производную от модуля (субградиент):
$$\frac{\partial R_{L1}}{\partial w_j} = \lambda \cdot \text{sign}(w_j) = \begin{cases} +\lambda, & w_j > 0 \\ -\lambda, & w_j < 0 \end{cases}$$
Обратите внимание: **сила штрафа постоянна ($\pm \lambda$) и совершенно НЕ ЗАВИСИТ от близости веса к нулю!**  
Даже когда вес уменьшился до $0.00001$, штраф продолжает давить на него с постоянной силой $\lambda$, принудительно заталкивая в нулевую точку $w_j = 0$. Происходит разреживание вектора весов (**Sparsity**) и автоматический отбор признаков.

---

### Геометрическое доказательство (Круг vs Ромб):
В задаче условной оптимизации Куна–Таккера регуляризация эквивалентна минимизации ошибки $\text{MSE}(w)$ при ограничении на бюджет весов:
- Для **L2 (Ridge)** бюджет ограничен евклидовой сферой: $w_1^2 + w_2^2 \le C$ — это **гладкий круг**.
- Для **L1 (Lasso)** бюджет ограничен суммой модулей: $|w_1| + |w_2| \le C$ — это **ромб с острыми углами на осях координат**.

Линии уровня эллипсоида квадратичной ошибки $\text{MSE}$ расширяются из центра оптимума $w^*$ до первого касания с допустимой областью:
1. В случае **L2 (круга)** касание гладкого эллипса с гладкой окружностью почти со 100% вероятностью происходит в произвольной точке дуги, где обе координаты отличны от нуля: $w_1 \ne 0, w_2 \ne 0$.
2. В случае **L1 (ромба)** эллипс при расширении почти всегда первым делом касается **острого угла ромба**, расположенного строго на координатной оси! В этой вершине одна из координат **строго равна нулю** ($w_1 = 0$ или $w_2 = 0$).

# Глава 6. Метрики качества (R2, MAE, RMSE, MSE) и проверка с эталоном scikit-learn

## 6.1. Математический смысл и формулы метрик регрессии

В машинном обучении качество работы модели оценивается вектором статистических метрик, каждая из которых имеет строгое физическое значение.

```python
y_pred_bgd = X_b @ bgd_res["w"]
residuals = y_raw - y_pred_bgd
```

### 1. Среднеквадратичная ошибка (MSE — Mean Squared Error)
$$\text{MSE} = \frac{1}{\ell} \sum_{i=1}^\ell (y_i - \hat{y}_i)^2 = \mathbf{96.85}$$
- **Смысл:** штрафует модель пропорционально квадрату ошибки, делая крупные промахи крайне невыгодными.
- **Связь с генератором данных:**  
  В Главе 1 мы установили, что в данные заложен шум $\sigma = 10.0$.  
  Теоретическая дисперсия шума: $\text{Var}(\varepsilon) = \sigma^2 = 10^2 = 100.0$.  
  Наш градиентный спуск достиг $\text{MSE} = 96.85 \approx 100.0$. Это доказывает, что модель полностью извлекла весь полезный линейный сигнал из признаков, а оставшаяся ошибка представляет собой чистый, некоррелированный белый шум!

### 2. Корень из среднеквадратичной ошибки (RMSE — Root Mean Squared Error)
$$\text{RMSE} = \sqrt{\text{MSE}} = \sqrt{96.85} = \mathbf{9.84}$$
- **Смысл:** возвращает ошибку в исходную физическую размерность целевой переменной $y$. Означает, что среднее квадратичное отклонение прогноза от факта составляет $9.84$ единицы (в пределах одного стандартного отклонения шума $\sigma = 10.0$).

### 3. Средняя абсолютная ошибка (MAE — Mean Absolute Error)
$$\text{MAE} = \frac{1}{\ell} \sum_{i=1}^\ell |y_i - \hat{y}_i| = \mathbf{7.85}$$
- **Смысл:** среднее арифметическое модуля отклонений. В отличие от RMSE, не возводит ошибки в квадрат и поэтому менее чувствительна к единичным случайным выбросам. Для гауссова шума теоретически $\text{MAE} \approx \sqrt{2/\pi} \cdot \sigma \approx 0.7979 \times 10 = 7.98$ (наш результат $7.85$ совпадает почти идеально).

### 4. Коэффициент детерминации ($R^2$ — R-squared Score)
$$R^2 = 1 - \frac{\sum_{i=1}^\ell (y_i - \hat{y}_i)^2}{\sum_{i=1}^\ell (y_i - \bar{y})^2} = 1 - \frac{\text{MSE}}{\text{Var}(y)} = \mathbf{0.9419}$$
- **Физический смысл:** Доля дисперсии целевой переменной $y$, объясненная обученной моделью регрессии.
- Значение $R^2 = 0.9419$ означает, что наша линейная модель успешно **объясняет 94.19% всего разброса целевой переменной**, и лишь оставшиеся $5.81\%$ приходятся на неустранимый случайный шум.

### Вопрос 1. В чём разница между Batch GD, Stochastic GD и Mini-batch GD? Каковы их вычислительные сложности и требования к памяти?
**Ответ:**  
1. **Batch GD (Пакетный):** вычисляет точный градиент по абсолютно всем $\ell$ объектам выборки. Сложность одного шага: $\mathcal{O}(\ell \cdot d)$. Требует загрузки всей матрицы данных в RAM. Траектория строго гладкая и детерминированная.
2. **Stochastic GD (Стохастический):** выбирает ровно $1$ случайный объект. Сложность шага: $\mathcal{O}(d)$ (в $\ell$ раз быстрее BGD). Память не расходуется (данные считываются потоком). Траектория сильно флуктуирует (стохастический шум), требует затухающего шага Роббинса–Монро.
3. **Mini-batch GD (Мини-пакетный):** компромиссный индустриальный стандарт. Градиент считается по небольшому батчу из $B$ объектов (обычно $B = 32, 64, 128, 256$):
   $$\nabla Q_{\text{batch}} = \frac{2}{B} \sum_{i=1}^B (x_i^T w - y_i) x_i$$
   Сложность шага: $\mathcal{O}(B \cdot d)$. Эффективно утилизирует векторные тензорные ядра современных GPU (SIMD-инструкции) и существенно сглаживает шум градиента по сравнению с чистым SGD.

---

### Вопрос 2. Сформулируйте и объясните условия теоремы Роббинса–Монро для сходимости SGD.
**Ответ:**  
Для того чтобы стохастический градиентный спуск сходился к точке глобального минимума с вероятностью 1, последовательность шагов обучения $\eta_k$ обязана удовлетворять двум условиям:
$$\mathbf{1) \quad \sum_{k=1}^\infty \eta_k = \infty \qquad \text{и} \qquad 2) \quad \sum_{k=1}^\infty \eta_k^2 < \infty}$$
- **Первое условие ($\sum \eta_k = \infty$):** Сумма всех шагов должна быть бесконечной. Это гарантирует, что оптимизатор сможет преодолеть сколь угодно большое расстояние до оптимума из любой начальной точки $w^0$, и шаги не иссякнут на полпути.
- **Второе условие ($\sum \eta_k^2 < \infty$):** Сумма квадратов шагов сходится к конечному числу. Так как дисперсия стохастического шума от отдельных объектов накапливается пропорционально $\sum \eta_k^2$, сходимость этого ряда гарантирует, что амплитуда случайных блужданий затухает до строгого нуля, обеспечивая стабилизацию весов в оптимуме $w^*$.  
Используемое в нашем коде расписание $\eta_k = \frac{\eta_0}{1 + 0.001 k} \sim \mathcal{O}(1/k)$ строго удовлетворяет обоим условиям.

### Вопрос 3. Почему в формуле аналитической Ridge-регрессии свободный член $w_0$ (bias) не регуляризуется и обнуляется в матрице `I_reg[0, 0] = 0`?
**Ответ:**  
Свободный член $w_0$ задает глобальный уровень сдвига плоскости регрессии по оси ответов: $w_0 \approx \mathbb{E}[y]$. Он не взаимодействует ни с какими входными признаками $x_j$ и не влияет на крутизну (сложность) модели.  
Если оштрафовать величину $w_0^2$, регуляризатор начнет принудительно стягивать прямую к началу координат $y = 0$, даже если все истинные ответы в выборке лежат около $+100$. Это вызовет грубое систематическое занижение прогнозов для 100% объектов.  
Регуляризоваться должны исключительно коэффициенты наклона $w_1, \dots, w_d$, определяющие чувствительность модели к колебаниям признаков.

### Вопрос 4. Откуда в коде `X.T @ X + l2_lambda * l * I_reg` взялся множитель `l = 1000` перед коэффициентом $\lambda$?
**Ответ:**  
Потому что в нашем коде функция потерь нормирована на число объектов $\ell = 1000$ (среднеквадратичная ошибка MSE):
$$Q_{L2}(w) = \frac{1}{\ell} \|Xw - y\|_2^2 + \lambda w^T I_{\text{reg}} w$$
Дифференцируя по вектору $w$ и приравнивая к нулю:
$$\frac{2}{\ell} X^T (Xw - y) + 2 \lambda I_{\text{reg}} w = \mathbf{0} \implies \frac{1}{\ell} X^T (Xw - y) + \lambda I_{\text{reg}} w = \mathbf{0}$$
Домножая все уравнение на скаляр $\ell$:
$$X^T (Xw - y) + \mathbf{\lambda \ell} I_{\text{reg}} w = \mathbf{0} \implies (X^T X + \mathbf{\lambda \ell} I_{\text{reg}}) w = X^T y$$
Если бы мы не умножили $\lambda$ на $\ell = 1000$, реальная сила штрафа оказалась бы в 1000 раз слабее заявленной.

### Вопрос 5. Почему L1-регуляризация (Lasso) зануляет веса (делает их разреженными / Sparse), а L2 (Ridge) лишь непрерывно сжимает?
**Ответ:**  
1. **Аналитически через производные штрафа:**
   - Для L2 производная равна $\frac{\partial}{\partial w} (\lambda w^2) = 2\lambda w$. По мере приближения веса к нулю ($w \to 0$) производная сама стремится к нулю! Около нуля штраф перестает толкать вес, поэтому веса остаются малыми ($0.039, 0.007$), но строго ненулевыми.
   - Для L1 производная равна $\frac{\partial}{\partial w} (\lambda |w|) = \lambda \cdot \text{sign}(w) = \pm \lambda = \text{const}$. Сила давления постоянна и не ослабевает даже при $w = 0.00001$. Штраф с постоянной силой пробивает окрестность нуля и принудительно обнуляет вес.
2. **Геометрически через форму допустимой области:**
   - Область ограничений L2 — гладкий круг ($w_1^2 + w_2^2 \le C$). Линии уровня эллипса ошибки касаются окружности в произвольной гладкой точке, где $w_1 \ne 0, w_2 \ne 0$.
   - Область ограничений L1 — ромб с острыми углами на осях координат ($|w_1| + |w_2| \le C$). Расширяющийся эллипс почти всегда первым делом касается острого угла ромба, лежащего строго на оси, где одна из координат строго равна нулю ($w_j = 0$).

### Вопрос 6. Что произойдет, если применить L2-регуляризацию к сырым данным БЕЗ предварительного масштабирования (`StandardScaler`)?
**Ответ:**  
Произойдет катастрофическое искажение штрафов!  
Пусть признак $x_1$ измерен в граммах ($[0, 1\,000\,000]$), а $x_2$ — в тоннах ($[0, 1]$).  
Чтобы оказывать одинаковое влияние на ответ $y$, истинный вес $w_1$ должен быть крошечным ($w_1 = 0.001$), а вес $w_2$ — огромным ($w_2 = 1000$).  
В штрафе L2 $\lambda (w_1^2 + w_2^2)$ слагаемое $w_2^2 = 10^6$, а $w_1^2 = 10^{-6}$.  
Регуляризатор со всей силой обрушится на признак $x_2$, просто потому что он измерен в тоннах, и практически полностью сотрет его влияние, при этом оставив $x_1$ нетронутым!  
**Вывод:** Регуляризация имеет физический смысл **только тогда, когда все признаки приведены к единой безразмерной шкале** с одинаковой дисперсией $\sigma = 1.0$.

### Вопрос 7. Какова вычислительная сложность обращения матрицы $(X^T X)^{-1}$ в МНК и почему при $d = 1\,000\,000$ признаков МНК падает, а градиентный спуск работает?
**Ответ:**  
Точное вычисление обратной матрицы размера $(d \times d)$ алгоритмом Гаусса или Холецкого имеет кубическую сложность:
$$\mathcal{O}(d^3)$$
При $d = 10^6$ потребуется $(10^6)^3 = 10^{18}$ элементарных операций, что физически нереализуемо даже на суперкомпьютерах, а сама матрица $10^6 \times 10^6$ займет 8 терабайт оперативной памяти.  
Градиентный спуск вообще не строит и не обращает матрицу $X^T X$. На каждом шаге он вычисляет только произведение матрицы на вектор со сложностью $\mathcal{O}(\ell \cdot d)$. При 100 итерациях и миллионе разреженных признаков расчет занимает считанные секунды.

### Вопрос 8. Как зависит сходимость градиентного спуска от максимального собственного значения Гессиана $\lambda_{\max}(H)$?
**Ответ:**  
Гессиан квадратичной функции потерь равен $H = \frac{2}{\ell} X^T X$.  
Градиент $\nabla Q$ удовлетворяет условию Липшица с константой $L = \lambda_{\max}(H)$.  
По теореме сходимости градиентных методов для выпуклых функций, алгоритм сходится строго при условии:
$$\mathbf{0 < \eta < \frac{2}{L} = \frac{2}{\lambda_{\max}(H)}}$$
Если $\eta \ge \frac{2}{L}$, длина шага превышает диаметр параболической чаши, возникает резонансный перелет через дно, и оптимизатор расходится в бесконечность.

### Вопрос 9. Докажите на примере одномерной параболы $f(w) = w^2$, почему при $\eta = 0.5$ возникают проблемы.
**Ответ:**  
Функция: $f(w) = w^2$, производная: $f'(w) = 2w$.  
Формула шага:
$$w^k = w^{k-1} - \eta \cdot 2 w^{k-1} = w^{k-1} (1 - 2\eta)$$
Множитель изменения веса равен $q = (1 - 2\eta)$.
- При $\eta = 0.05 \implies q = 1 - 0.1 = 0.9$ (монотонное затухание $0.9^k \to 0$);
- При $\eta = 0.5 \implies q = 1 - 1.0 = 0.0$ (прыжок в ноль);
- При $\eta > 0.5$ (например $\eta = 0.6$) $\implies q = 1 - 1.2 = -0.2$ (знак веса меняется на каждом шаге — перелет через дно и колебания);
- При $\eta = 1.0 \implies q = 1 - 2.0 = -1.0$ (незатухающие осцилляции $w, -w, w, -w \dots$);
- При $\eta > 1.0 \implies |q| > 1$ (экспоненциальный улет в бесконечность).

### Вопрос 10. Почему минимально достижимое MSE в нашем эксперименте равно $\approx 96.85$, а не $0.0$? Означает ли это, что модель недообучилась?
**Ответ:**  
НЕТ, модель обучилась идеально!  
При генерации данных через `make_regression` был задан параметр некоррелированного аддитивного шума `noise = 10.0`.  
Теоретическая дисперсия неустранимого шума природы генератора:
$$\text{Var}(\varepsilon) = \sigma^2 = 10.0^2 = \mathbf{100.0}$$
Ни одна модель в мире не может предсказать чисто случайный гауссов шум.  
Полученная ошибка $\text{MSE} = 96.85 \approx 100.0$ строго соответствует теоретическому байесовскому пределу ошибки (**Bayes Error Rate**). Если бы модель показала $\text{MSE} = 0$, это означало бы грубейшую ошибку переобучения (заучивание шума).

### Вопрос 11. Как устроен критерий останова по Фото 2: $\|w^k - w^{k-1}\| < \varepsilon$? Почему проверяется норма вектора весов, а не изменение ошибки $|\Delta \text{MSE}|$?
**Ответ:**  
Критерий $\|w^k - w^{k-1}\|_2 < \varepsilon$ измеряет евклидово расстояние между последовательными векторами весов в $\mathbb{R}^d$ по теореме Пифагора:
$$\sqrt{\sum_{j=0}^d (w_j^k - w_j^{k-1})^2} < 10^{-5}$$
**Почему нельзя ориентироваться только на изменение ошибки $|\text{MSE}_k - \text{MSE}_{k-1}|$?**  
Потому что на пологих плато или в узких оврагах функция потерь может временно почти не менять свое значение ($|\Delta \text{MSE}| < 10^{-6}$), в то время как веса $w$ продолжают активно дрейфовать к оптимуму на большие расстояния. Проверка нормы весов гарантирует, что само физическое положение модели в пространстве параметров полностью стабилизировалось.

### Вопрос 12. Как на практике выбирают оптимальное значение $\lambda$? Что такое кросс-валидация и как устроен `RidgeCV`?
**Ответ:**  
Гиперпараметр $\lambda$ нельзя выбирать по обучающей выборке, так как минимальная ошибка на Train всегда достигается при $\lambda = 0$ (чистый МНК).  
Оптимальный $\lambda$ выбирается методом **K-Fold кросс-валидации**:
1. Выборка делится на $K$ равных частей (фолдов, обычно $K = 5$ или $10$).
2. Для каждого значения $\lambda$ из логарифмической сетки модель $K$ раз обучается на $K-1$ фолдах и тестируется на оставшемся валидационном фолде.
3. Ошибки валидации усредняются. Оптимальным признается то значение $\lambda^*$, которое минимизирует среднюю ошибку на отложенных данных:
   $$\lambda^* = \arg\min_\lambda \text{CV\_Score}(\lambda)$$
Класс `RidgeCV` из `scikit-learn` автоматизирует этот процесс, используя эффективный аналитический трюк разложения Generalized Cross-Validation (GCV) без повторного многократного обучения.

### Вопрос 13. Что такое компромисс между смещением и дисперсией (Bias-Variance Tradeoff) при изменении $\lambda$?
**Ответ:**  
Полная ошибка модели на тесте раскладывается на три слагаемых:
$$\text{Expected Test Error} = \text{Bias}^2 + \text{Variance} + \sigma_{\text{noise}}^2$$
- **При $\lambda \to 0$ (МНК):**  
  Смещение минимально ($\text{Bias} \approx 0$), но дисперсия весов высока ($\text{Variance} \gg 0$). Модель нестабильна и склонна к переобучению при шуме.
- **При $\lambda \to \infty$:**  
  Дисперсия падает до нуля ($\text{Variance} \to 0$, все веса стянуты в 0), но систематическое смещение становится колоссальным ($\text{Bias}^2 \gg 0$). Модель недообучена (Underfitting) и предсказывает константу.
- **Оптимум $\lambda^*$:**  
  Точка минимума суммы $\text{Bias}^2 + \text{Variance}$, где веса достаточно сжаты для подавления шума, но ещё не потеряли полезный сигнал.

### Вопрос 14. Каков физический смысл коэффициента детерминации $R^2 = 0.9419$? Может ли $R^2$ быть отрицательным?
**Ответ:**  
1. **Смысл:** $R^2 = 1 - \frac{\text{MSE}}{\text{Var}(y)} = 0.9419$. Наша линейная регрессия объясняет **94.19% всей дисперсии (разброса) целевой переменной**, оставляя необъясненными лишь 5.81% белого шума.
2. **Может ли $R^2$ быть отрицательным?**  
   **ДА, МОЖЕТ!** Если модель предсказывает хуже, чем просто тривиальная константа — выборочное среднее $\bar{y}$.  
   В формуле $R^2 = 1 - \frac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}}$, если среднеквадратичная ошибка модели превышает дисперсию данных ($\text{MSE} > \text{Var}(y)$), дробь становится больше 1, и $R^2 < 0$. Это верный признак грубой ошибки обучения или применения модели к совершенно неадекватным данным.

### Вопрос 15. Почему в формуле градиента MSE $\nabla Q(w) = \frac{2}{\ell} X^T (Xw - y)$ стоит матрица $X^T$, а не просто $X$? Как проверить это по размерностям?
**Ответ:**  
1. **По смыслу операции:**  
   Градиент функции $Q(w)$ берется по вектору весов $w \in \mathbb{R}^d$. Значит, сам вектор градиента обязан иметь в точности такую же размерность: $(d \times 1)$ — по одной частной производной $\frac{\partial Q}{\partial w_j}$ для каждого из $d$ весов.
2. **Проверка по размерностям матриц:**
   - Матрица $X$ имеет размерность $(\ell \times d) = (1000 \times 3)$;
   - Вектор невязок $(Xw - y)$ имеет размерность $(\ell \times 1) = (1000 \times 1)$;
   - Если попытаться умножить $X \cdot (Xw - y)$, операция невозможна: $(1000 \times 3)$ нельзя умножить на $(1000 \times 1)$ (внутренние размерности 3 и 1000 не совпадают);
   - При транспонировании $X^T$ получает размерность $(d \times \ell) = (3 \times 1000)$;
   - Матричное произведение:
     $$\underbrace{X^T}_{(3 \times 1000)} \times \underbrace{(Xw - y)}_{(1000 \times 1)} = \underbrace{\nabla Q}_{(3 \times 1)}$$
   Результат — строго вектор градиента из 3 компонент для обновления весов $w_0, w_1, w_2$!
