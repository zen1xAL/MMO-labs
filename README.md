## Краткое описание работ

### [Лабораторная работа №1](lab1/)
* **Тема:** Знакомство с инструментами сбора и подготовки данных в машинном обучении.
* **Вариант 7:** Моделирование и подготовка разнотипных данных, анализ распределений, работа со статистическими аномалиями и нормализацией.
* **Стек:** Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-Learn.

### [Лабораторная работа №2](lab2/)
* **Тема:** Разведочный и предиктивный анализ данных (EDA).
* **Датасет:** *Student Performance Factors* (6 607 наблюдений, 20 атрибутов).
* **Выполненные этапы:**
  1. Статистический и визуальный анализ пропусков (90 в `Parental_Education_Level`, 78 в `Teacher_Quality`, 67 в `Distance_from_Home`, всего 235), их устранение модальной импутацией с валидацией.
  2. Обнаружение и винзоризация выбросов по правилу Тьюки (1.5×IQR) для признаков `Hours_Studied`, `Tutoring_Sessions`, `Exam_Score` (включая аномалию 101 балл).
  3. Feature Engineering: создание новых метрик `Study_to_Sleep_Ratio`, `Academic_Effort_Index`, `Score_Growth`.
  4. Кодирование категориальных признаков (Binary Mapping + One-Hot Encoding).
  5. Масштабирование признаков (StandardScaler vs MinMaxScaler).
  6. Анализ корреляционной матрицы Пирсона.

### [Лабораторная работа №3](lab3/)
* **Тема:** Градиентный спуск и методы регуляризации линейных моделей.
* **Вариант 7 (нечетный):** **L2-регуляризация (Ridge Regression)** с сеткой из 20 значений $\lambda \in [0.001, 1000]$.
* **Выполненные этапы:**
  1. Синтез данных множественной регрессии ($N=1000, d=2$, гауссов шум $\sigma=10.0$) и стандартизация признаков StandardScaler.
  2. Аналитическое МНК-решение ($w^* = (X^T X)^{-1} X^T y$).
  3. Пакетный градиентный спуск (BGD): шаг $w^k = w^{k-1} - \eta_k \nabla Q$ с критерием останова $\|w^k - w^{k-1}\| < \varepsilon$ (сходимость за 124 итерации, разность с МНК $< 10^{-4}$).
  4. Стохастический градиентный спуск (SGD): покоординатный шаг со снижением темпа обучения по правилу Роббинса-Монро.
  5. Экспериментальное исследование чувствительности к темпу обучения $\eta \in \{0.001, 0.01, 0.05, 0.1, 0.5\}$.
  6. Реализация L2 Ridge регуляризации: траектории сжатия весов без штрафования свободного члена ($w_0$), сравнительный анализ эффекта разреживания весов с L1 Lasso.
  7. Полная автоматизированная верификация по стандарту `mmo-lab-qa` (85/85 тестов пройдено).

### [Лабораторная работа №4](lab4/)
* **Тема:** Классификация данных. Логистическая регрессия, Метод опорных векторов (SVM) и Решающие деревья (CART).
* **Вариант 7:** Кредитный скоринг и бинарная классификация на датасете `Bankloan.csv` (1150 наблюдений, 8 числовых признаков, 700 исторических клиентов, 450 новых кредитных соискателей).
* **Выполненные этапы:**
  1. Первичный анализ и очистка данных: разделение на 700 размеченных записей (517 надежных, 183 дефолтных, дисбаланс 2.8:1) и 450 записей без меток для скоринга.
  2. Разведочный анализ (EDA): анализ межквартильных диапазонов (IQR), корреляционный анализ (выявление факторов максимального риска `debtinc` $r=+0.39$ и финансовой устойчивости `employ` $r=-0.28$).
  3. Стратифицированное разбиение выборки 80/20 с сохранением $26.1\%$ доли дефолтов в обеих подвыборках и стандартизация признаков `StandardScaler` без утечки данных (fit strictly on train).
  4. Обучение и сравнительный анализ 4 моделей классификации:
     - **Логистическая регрессия:** анализ коэффициентов и отношений шансов ($\text{OR}_{\text{debtinc}} = 2.44$, $\text{OR}_{\text{employ}} = 0.48$), наивысший Recall ($62.16\%$) и минимальные кредитные риски ($FN = 14$).
     - **Linear SVM:** лучшая общая модель (Accuracy $83.57\%$, Precision $73.33\%$, ROC-AUC $0.8699$, PR-AUC $0.7410$).
     - **RBF SVM:** нелинейная гиперповерхность с гауссовым ядром (Accuracy $80.71\%$, ROC-AUC $0.8066$).
     - **CART Decision Tree:** регуляризованное дерево решений (`max_depth=3`, `min_samples_leaf=15`) с корневым порогом по долговой нагрузке `debtinc <= 14.7%`.
  5. Сравнительный анализ матриц ошибок, ROC и PR кривых.
  6. Практический скоринг пула 450 соискателей с консервативным порогом отсечения $\tau = 0.35$: одобрено 336 заявок ($74.7\%$), отклонено 114 высокорисковых заявок ($25.3\%$).
  7. Автоматизированная верификация Senior QA инженером (`qa_test_suite_lab4.py` — 131/131 тестов пройдено).
